# Sound effects (engine/public/sfx)

All CC0 (no attribution required). 48 kHz stereo WAV. The engine mounts them itself on each element's entry.

| File | Used for | Source |
|---|---|---|
| `key-1..8`, `key-space` | typewriter labels, one per character | "Keyboard Sounds" by unicaegames, OpenGameArt (CC0) |
| `click` | pin | Kenney UI Audio `mouseclick1` + `mouserelease1` (CC0) |
| `tap` | tape | Kenney UI Audio `click3` (CC0) |
| `pop` | pop-in elements | Kenney Interface Sounds `drop_001` (CC0) |
| `slam-1..3` | number cards, stamps, title card | Kenney Impact Sounds `impactSoft_medium_001-003` + Interface `tick_002` (CC0) |
| `swish-1..3` | slides, red string | Kenney RPG Audio `cloth2-4` (CC0) |
| `page-1..3` | page-push transitions | Kenney RPG Audio `bookFlip1-3` (CC0) |
| `paper-place-1..2` | slapped / dropped paper | Kenney RPG Audio `bookPlace1-2` (CC0) |
| `cut` | hard cuts | Kenney RPG Audio `knifeSlice` (CC0) |
| `whoosh`, `impact`, `riser` | optional `SFX()` accents | synthesised (no source material) |

Kenney packs: https://kenney.nl/assets · OpenGameArt: https://opengameart.org/content/keyboard-sounds
Add new sounds only from CC0 or public-domain sources and record them here.
